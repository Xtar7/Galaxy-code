# DESIGN.md

<!-- impeccable:design-schema 1 -->

## World

暖白纸面（`#faf9f7`）上的目录式卡片画廊。单一暖橙强调色（`#e85d26`，继承自仓库既有的"落日橙盾牌"favicon 体系）承担控件高亮、FREE 标签和聚焦环；正文用深墨色（`#1c1a17`），次要文字用暖灰（`#6d6860`，从墨色取暖而非冷灰）。卡片是页面唯一的"容器"角色：细边框（`#e5e1da`）+ 轻量投影（带偏移的柔影，非零偏移彩色光晕），卡片内部不再嵌套卡片。

## Typography

正文 15px，`Avenir Next` / `PingFang SC` / `Microsoft YaHei` / system-ui 栈（无自建展示字体，工具型页面以系统栈为诚实选择）。统计数字用 `font-variant-numeric: tabular-nums` 对齐；模型 id 用系统等宽栈（`ui-monospace, "Cascadia Code", "SF Mono", Consolas`）——等宽用于数据/标识符本身，不作为"技术感"的装饰。

## Color

| 角色 | 值 |
|---|---|
| 底色 | `#faf9f7` |
| 卡片/控件 | `#ffffff` |
| 正文 | `#1c1a17` |
| 次要文字 | `#6d6860` |
| 边框 | `#e5e1da` |
| 强调 | `#e85d26` |
| 强调弱化底 | `#fbe9e0` |

## Layout

880px 居中单栏。第一视口：标题+副标题（左）与两个统计块（右）并排；其下搜索框+筛选标签一行；再下"数据更新于 xx"+刷新按钮一行；卡片列表按名称排序。移动端（≤560px）卡片塌成单栏，操作按钮改为横向排列。

## Components

- **卡片行**：网格 `1fr auto`，名称/id/元信息占左列，操作按钮占右列纵向居中；`FREE` 标签用强调色弱化底，其余标签用边框色弱化底。
- **筛选标签**：胶囊按钮，选中态为强调色实心，未选中为白底描边。
- **统计块**：白底描边小卡，数字大号加粗，标签小号次要色；数值为 0 时数字降级为次要色，提示"暂为空类"而非缺陷。

## States

加载中（"加载中…"占位）、空结果（"没有匹配的模型"）、加载失败（提示检查后端）、复制成功（按钮/id 文字临时变为"已复制 ✓"）、0 值统计降级色。悬停：按钮和标签切换到强调色描边/文字。

## Motion

单一编排时刻：列表渲染无动画（工具页），复制成功用文字切换 + 1.2s 自动还原，聚焦用 3px 弱化强调色光环（`box-shadow`）。不做逐卡片入场动画——这是数据目录，不是展示页。

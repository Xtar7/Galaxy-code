HeaderScope · 响应头安全审计
粘贴或导入脱敏的 HTTP 响应头，审计响应头与 Cookie 安全配置 — 纯浏览器运行，不上传、不请求网络
本工具只解析你粘贴/导入的脱敏响应头文本，全程在浏览器本地运行，不发起任何网络请求、不上传数据。请仅对获得授权的资产执行安全审计，切勿粘贴含真实会话 Cookie 值的响应头。
粘贴响应头
支持原始 HTTP 报文、浏览器 DevTools 导出、curl 抓包等；自动识别头行并解析 Cookie。也可从右上角导入脱敏文本文件。

部署上下文
同一段响应头在不同部署条件下结论不同。填入实际部署信息，让审计结果贴合真实环境，而非机械打勾。
提示：HSTS、Cookie 等检查的结论会随「站点协议」与「是否承载敏感 Cookie」变化。留空则按通用默认判断；响应中出现 HSTS 头会据此推断为 HTTPS。
判定口径
HeaderScope 不做「缺头就打红」。每项检查都会给出适用条件：例如站点未启用 HTTPS 时 HSTS 无意义；CSP 含 'unsafe-inline' 时不能认定安全；Cookie 不承载会话时 SameSite 缺失只是低优先级建议，而非高危。

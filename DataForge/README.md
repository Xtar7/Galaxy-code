# DataForge — 浏览器端数据工作台

> 纯前端、零依赖（除 XLSX 导出外）、无需后端的数据处理工具。上传 CSV/TSV/JSON，在浏览器中完成筛选、合并、拆分、清洗、字段重组、多表关联等操作。

## 在线演示

**[GitHub Pages 在线使用](https://xtar7.github.io/dataforge/)**

## 功能特性

| 模块 | 功能 |
|------|------|
| 筛选与合并 | 多文件选择、列选择、多条件筛选、数据预览（1/3/5行）、纵向合并/交集/不合并 |
| 字段映射重组 | 跨表字段挑选、计算列公式（`{单价}*{数量}`）、正则提取特定值 |
| 多表关联 | 左连接/内连接，按关键字段关联多个表 |
| 条件拆分 | 按列值拆分 / 按自定义条件拆分 |
| 数据清洗 | 去空格、删空行/空列、去重、填充空值、统一列名大小写 |
| 预览与导出 | 表格预览、导出 XLSX/CSV/Markdown、一键复制到剪贴板 |

## 使用方式

### 方式一：GitHub Pages（推荐）
1. Fork 本仓库
2. 进入 Settings → Pages → Source 选择 `main` 分支
3. 访问 `https://xtar7.github.io/dataforge/`

### 方式二：本地打开
直接双击 `index.html`，用浏览器打开即可。无需安装、无需网络。

### 方式三：内网部署
将 `index.html` 拷贝到内网任意服务器或共享目录，通过浏览器访问即可。

## 支持的文件格式

- `.csv` — 逗号分隔
- `.tsv` / `.txt` — 制表符分隔
- `.json` — JSON 数组格式

## 正则提取示例

| 场景 | 正则表达式 | 说明 |
|------|-----------|------|
| 提取冒号后值 | `:([^;]+)` | `xx:100;yy:200` → `100`, `200` |
| 提取引号内容 | `"([^"]+)"` | `name="张三"` → `张三` |
| 提取数字 | `(\d+)` | `ID:12345` → `12345` |
| 提取邮箱 | `[\w.-]+@[\w.-]+` | 匹配邮箱地址 |

## 计算列公式示例

| 公式 | 结果 |
|------|------|
| `{单价}*{数量}` | 金额计算 |
| `{姓}+{名}` | 姓名拼接 |
| `{分数}/100` | 百分比转换 |

## 隐私说明

**所有数据处理均在浏览器本地完成**，文件不会上传到任何服务器。适合处理敏感数据。

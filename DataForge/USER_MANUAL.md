## 1. 快速开始

### 第一步：打开网页

访问 `https://xtar7.github.io/Galaxy-code/` 或双击本地 `index.html`。

### 第二步：上传文件

点击右上角 **「上传文件」** 按钮，选择你的 CSV/TSV/JSON 文件。支持同时上传多个文件。

### 第三步：选择功能

点击顶部标签切换功能模块，配置参数后点击执行按钮。

### 第四步：导出结果

处理完成后切换到 **「预览与导出」** 标签，选择导出格式下载。

## 3. 功能详解

### 3.1 上传文件

#### 支持的格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| CSV | `.csv` | 逗号分隔，支持引号包裹的字段 |
| TSV | `.tsv` `.txt` | 制表符分隔 |
| JSON | `.json` | JSON 数组，每个元素是一行数据 |

#### 操作步骤

1. 点击右上角 **「上传文件」** 按钮
2. 在弹出的文件选择框中，按住 `Ctrl`（Windows）或 `Cmd`（Mac）可多选文件
3. 文件上传后会在「已上传文件」区域显示文件名、行数和列数
4. 鼠标悬停在文件上，点击 **「删除」** 可移除该文件

#### 注意事项

- Excel 文件（`.xlsx`）请先另存为 CSV 格式再上传
- 文件编码建议为 UTF-8，避免中文乱码
- 首行会被识别为表头（列名）

### 3.2 筛选与合并

#### 功能说明

从多个表中筛选数据，选择需要的列，按指定方式合并成一张新表。

#### 操作步骤

**① 选择要处理的表**

勾选「已上传文件」区域显示的文件复选框。默认全部勾选。

**② 数据预览**

选择预览行数（1行 / 3行 / 5行），下方会显示每个选中文件的表头和数据样例。

> 预览表格支持**横向滚动**，列数多时可以左右滑动查看。

**③ 选择要保留的列**

- 留空 = 保留全部列
- 勾选特定列 = 只保留这些列

**④ 添加筛选条件（可选）**

点击 **「+ 添加条件」**，配置筛选规则：

| 操作符 | 说明 | 示例 |
|--------|------|------|
| 等于 | 完全匹配 | `状态 == '已完成'` |
| 不等于 | 排除匹配 | `类别 != '测试'` |
| 包含 | 子串匹配 | `姓名 contains '张'` |
| 开头是 | 前缀匹配 | `编号 starts 'ORD'` |
| 结尾是 | 后缀匹配 | `邮箱 ends '@company.com'` |
| 大于 / 小于 / 大于等于 / 小于等于 | 数值比较 | `金额 > 1000` |
| 为空 | 空值判断 | `备注 empty` |
| 非空 | 非空判断 | `电话 notempty` |

**⑤ 选择合并方式**

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| 纵向合并（行拼接） | 把所有表的行堆叠在一起 | 多个月份数据合并 |
| 取交集 | 只保留所有表都有的列和行 | 找出共同数据 |
| 不合并 | 分别处理每个表，生成多个结果 | 各表独立筛选 |

**⑥ 点击「应用筛选」**

处理完成后自动跳转到「预览与导出」标签。

### 3.3 字段映射重组

#### 功能说明

从多个表中挑选字段，重新组合成一张新表。支持计算列和正则提取。

#### 操作步骤

**① 添加字段映射**

点击 **「+ 添加字段」**，配置每一列：

| 配置项 | 说明 |
|--------|------|
| 选择表 | 数据来源的文件 |
| 选择字段 | 来源文件中的列名（选「使用公式」可输入计算公式）|
| 新列名 | 结果表中的列名 |
| 公式 | 当字段选择「使用公式」时生效 |

**② 添加正则提取规则（可选）**

点击 **「+ 添加提取规则」**，从某一列中提取特定值：

| 配置项 | 说明 |
|--------|------|
| 选择表 | 数据来源的文件 |
| 选择列 | 要提取的原始列 |
| 正则表达式 | 匹配模式 |
| 新列名 | 提取结果的新列名 |
| 提取所有匹配 | 勾选后提取所有匹配值，用逗号分隔 |

**③ 点击「执行重组」**

#### 计算列公式语法

使用 `{列名}` 引用字段，支持基本运算：

| 公式示例 | 说明 |
|----------|------|
| `{单价}*{数量}` | 两列相乘 |
| `{金额}/100` | 数值除法 |
| `{姓}+{名}` | 字符串拼接 |
| `{分数1}+{分数2}` | 多列相加 |

#### 正则提取示例

**场景**：列值为 `xxxxx:10005;xxxx:55658`，想提取 `10005` 和 `55658`

| 正则表达式 | 提取结果 |
|-----------|----------|
| `:([^;]+)` | `10005`（第一个匹配）|
| `:([^;]+)` + 勾选「提取所有匹配」 | `10005, 55658` |

更多正则示例：

| 场景 | 正则表达式 | 输入 | 输出 |
|------|-----------|------|------|
| 提取引号内容 | `"([^"]+)"` | `name="张三"` | `张三` |
| 提取数字 | `(\d+)` | `ID:12345` | `12345` |
| 提取邮箱 | `[\w.-]+@[\w.-]+` | `联系: admin@site.com` | `admin@site.com` |
| 提取括号内容 | `\(([^)]+)\)` | `地点(北京)` | `北京` |

### 3.4 多表关联

#### 功能说明

类似 SQL 的 JOIN 操作，按关键字段把多个表关联成一张大表。

#### 操作步骤

**① 确认主表**

主表为**第一个上传的文件**。

**② 添加关联**

点击 **「+ 添加关联」**，配置关联关系：

| 配置项 | 说明 |
|--------|------|
| 选择关联表 | 要与主表关联的文件 |
| 关联字段 | 关联表中用于匹配的列 |
| 主表字段 | 主表中用于匹配的列 |

**③ 选择关联方式**

| 方式 | 说明 | 结果 |
|------|------|------|
| 左连接 | 保留主表所有行 | 关联不上的显示为空 |
| 内连接 | 只保留匹配的行 | 两边都有的才保留 |

**④ 点击「执行关联」**

#### 关联示例

**主表：订单表**

| 订单ID | 客户ID | 金额 |
|--------|--------|------|
| A001 | C100 | 500 |
| A002 | C200 | 800 |

**关联表：客户表**

| 客户ID | 客户名 | 电话 |
|--------|--------|------|
| C100 | 张三 | 138**** |
| C300 | 李四 | 139**** |

**左连接结果**：

| 订单ID | 客户ID | 金额 | 客户名 | 电话 |
|--------|--------|------|--------|------|
| A001 | C100 | 500 | 张三 | 138**** |
| A002 | C200 | 800 | （空） | （空） |

**内连接结果**：

| 订单ID | 客户ID | 金额 | 客户名 | 电话 |
|--------|--------|------|--------|------|
| A001 | C100 | 500 | 张三 | 138**** |

### 3.5 条件拆分

#### 功能说明

把一张表按条件拆分成多张表。

#### 方式一：按列值拆分

1. 选择「源表」
2. 选择「按哪列拆分」
3. 点击「执行拆分」

**示例**：按「部门」列拆分

| 原始表 | 拆分结果 |
|--------|----------|
| 销售部、技术部、财务部混合 | 销售部表、技术部表、财务部表 |

#### 方式二：按自定义条件拆分

在文本框中输入多行条件，每行一个：

```
status == 'active'
age > 18
name contains '张'
```

**执行逻辑**：
- 第一行条件匹配的行 → 表1
- 第二行条件匹配且未被表1包含的行 → 表2
- 以此类推
- 剩余未匹配的行 → 「其他」表

### 3.6 数据清洗

#### 功能说明

批量清洗数据，去除脏数据、统一格式。

#### 清洗选项

| 选项 | 说明 |
|------|------|
| 去除首尾空格 | 删除每个单元格前后的空格和换行 |
| 删除完全空行 | 所有列都为空的行会被删除 |
| 删除完全空列 | 所有行都为空的列会被删除 |
| 删除重复行 | 整行内容完全相同的只保留一条 |
| 填充空值 | 把空单元格填充为指定值 |
| 统一列名大小写 | 所有列名转为小写 |

#### 空值填充方式

当勾选「填充空值」时，可选择：

| 方式 | 填充内容 |
|------|----------|
| 空字符串 | `''` |
| 0 | `0` |
| N/A | `'N/A'` |

---

### 3.7 预览与导出

#### 结果切换

如果一次操作生成了多个结果表（如拆分、不合并筛选），会显示结果切换标签，点击切换查看。

#### 导出格式

| 格式 | 用途 |
|------|------|
| XLSX | Excel 格式，可直接用 Excel 打开 |
| CSV | 逗号分隔，通用格式 |
| Markdown | Markdown 表格，适合文档 |
| 复制 | 复制 TSV 格式到剪贴板，直接粘贴到 Excel |

#### 复制到剪贴板

点击「复制」按钮后，打开 Excel 按 `Ctrl+V` 即可粘贴。

## 4. 实战案例

### 案例 1：合并多个月份销售数据

**场景**：有 1月.csv、2月.csv、3月.csv，结构相同，要合并成一张表。

**步骤**：
1. 上传 3 个文件
2. 切换到「筛选与合并」
3. 确认 3 个文件都被勾选
4. 合并方式选「纵向合并（行拼接）」
5. 点击「应用筛选」
6. 导出 XLSX

### 案例 2：从混合字段中提取信息

**场景**：有一列「设备信息」内容为 `型号:iPhone14;序列号:ABC123;位置:北京`，要提取出型号和位置。

**步骤**：
1. 切换到「字段映射重组」
2. 添加字段映射：选择原表和需要的其他字段
3. 添加提取规则 1：
   - 列：设备信息
   - 正则：`型号:([^;]+)`
   - 新列名：型号
4. 添加提取规则 2：
   - 列：设备信息
   - 正则：`位置:([^;]+)`
   - 新列名：位置
5. 点击「执行重组」

### 案例 3：关联订单与客户信息

**场景**：订单表有「客户ID」，客户表有「客户ID、客户名、电话」，要生成完整订单表。

**步骤**：
1. 先上传订单表，再上传客户表（订单表是主表）
2. 切换到「多表关联」
3. 添加关联：
   - 关联表：客户表
   - 关联字段：客户ID
   - 主表字段：客户ID
4. 关联方式选「左连接」
5. 点击「执行关联」

### 案例 4：按条件拆分数据

**场景**：员工表有「部门」列，要按部门拆分成多个文件。

**步骤**：
1. 切换到「条件拆分」
2. 选择源表
3. 选择列：部门
4. 点击「执行拆分」
5. 导出时逐个结果表下载

## 5. 常见问题

### Q1：上传 Excel 文件显示乱码？

Excel 的 `.xlsx` 是二进制格式，不能直接按文本读取。请先在 Excel 中「另存为」→「CSV (逗号分隔)」后再上传。

### Q2：中文显示乱码？

确保文件保存为 **UTF-8 编码**。在记事本中保存时选择「编码：UTF-8」。

### Q3：数据量很大（几万行）会卡吗？

当前版本所有数据在浏览器内存中处理。建议：
- 单次处理不超过 5 万行
- 关闭其他浏览器标签页释放内存
- 大数据量建议分批处理

### Q4：刷新页面后数据丢失？

是的，当前版本数据仅保存在内存中，刷新会丢失。处理完成后请及时导出保存。

> 如需持久化，可联系开发者添加 LocalStorage 自动保存功能。

### Q5：导出的 CSV 用 Excel 打开中文乱码？

导出的 CSV 已包含 UTF-8 BOM 标记，正常情况下 Excel 能正确识别。如仍乱码：
1. 用记事本打开 CSV
2. 「另存为」→ 编码选「UTF-8 BOM」
3. 再用 Excel 打开

### Q6：可以处理 JSON 文件吗？

可以。JSON 文件需要是**数组格式**，每个数组元素是一个对象，对象的 key 作为列名：

```json
[
  {"姓名": "张三", "年龄": 25},
  {"姓名": "李四", "年龄": 30}
]
```

### Q7：公式计算报错？

计算列公式目前仅支持：
- 基本四则运算：`+` `-` `*` `/` `%`
- 用 `{列名}` 引用字段
- 不支持函数调用（如 SUM、IF 等）

如需复杂计算，建议导出后用 Excel 处理。

## 6. 快捷键与技巧

### 文件上传

| 技巧 | 说明 |
|------|------|
| 多选文件 | 按住 `Ctrl` / `Cmd` 点击多个文件 |

|------|------|

| 技巧 | 说明 |
|------|------|

### 导出

| 技巧 | 说明 |
|------|------|
| 快速粘贴到 Excel | 点击「复制」→ Excel 中 `Ctrl+V` |

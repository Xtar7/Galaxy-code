HashDock · 文件完整性校验
单文件 / 批量 SHA-256 计算、清单导入导出、前后哈希比较 — 纯浏览器运行，不上传、不请求网络
哈希相同可以支持文件内容一致性的判断，但不能单独证明文件来源可信或文件从未被篡改；可信基准和清单本身也需要保护（离线存放、独立渠道分发、签名、双人保管等）。
选择文件（单文件 / 批量）
选择文件后立即计算 SHA-256（Web Crypto，256KiB 分块读取，全程本地，不上传）。
点击选择文件，或将文件拖到这里（支持多选）
基准清单
导入既有清单作为对比基准；「导出清单」产物即可被 sha256sum -c 直接复核（双空格格式，容忍单空格与 * 前缀）。
前后基线
粘贴操作前导出的清单为基线后重新计算，结果区会额外给出「与基线比」列 — 这就是文件前后哈希比较。
校验结果与前后对比
导入基准后，计算结果自动逐项比对；点击哈希值可复制。「前后对比」按文件名列匹配。

本地版 / 命令行参考
Web 版受浏览器文件访问限制；目录批处理、GB 级大文件分块计算与离线清单复核请用下列命令（点击复制）。
生成清单并复核（Linux / Git Bash）：
sha256sum ./* > manifest.txt 2>/dev/null
sha256sum -c manifest.txt        # 不符会报 FAILED
macOS 生成 / 目录批处理（GB 级大文件友好）：
shasum -a 256 ./* > manifest.txt
find /path/to/dir -type f -exec sha256sum {} + > manifest.txt
前后对比：只重算清单中出现过的文件，diff 出差异：
awk '{print $2}' manifest_old.txt | while read -r f; do
  [ -f "$f" ] && sha256sum "$f"
done > manifest_now.txt
diff manifest_old.txt manifest_now.txt   # 有输出即存在变更

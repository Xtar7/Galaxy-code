🖥️ 本地版 / 命令行参考

目录批处理 · 大文件分块 · 离线复核
Web 版受浏览器文件访问限制；目录批处理、GB 级文件分块计算与离线清单复核请用下列命令（点击复制）。
生成清单并复核（Linux / Git Bash）：
sha256sum ./* > manifest.txt 2>/dev/null
sha256sum -c manifest.txt        # 不符会报 FAILED
macOS 生成 / 目录批处理（GB 级大文件友好）：
shasum -a 256 ./* > manifest.txt
find /path/to/dir -type f -exec sha256sum {} + > manifest.txt
前后对比：只重算清单中出现过的文件，diff 出差异：
awk '{print $2}' manifest_old.txt | while read -r f; do
  [ -f "$f" ] && sha256sum "$f"
done > manifest_now.txt
diff manifest_old.txt manifest_now.txt   # 有输出即存在变更
